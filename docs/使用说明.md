# List Reminder

原生 macOS 待办清单，带可交互的桌面玻璃小组件。

## 运行环境与安装

- Apple Silicon Mac（M 系列芯片），macOS 26 或更新版本。
- 将 `List Reminder.app` 拖入“应用程序”，然后双击打开；也可以直接运行本文件夹中的应用。
- 应用使用本机临时签名，尚未进行 Apple 公证。若另一台 Mac 的系统阻止运行，请在确认来源后，按系统“隐私与安全性”中的正常提示处理。
- 不需要联网、账号、辅助功能权限或屏幕录制权限。

## 使用

1. 在主窗口底部输入待办，按回车添加。
2. 双击主窗口中的待办，标记为完成；在“已完成”页面双击可以恢复。
3. 桌面上的小组件同步显示未完成待办。双击某行直接完成，单击不完成，也不打开主窗口或激活主应用。
4. 点击“小组件外观”，可调节背景透明度（0–90%）、宽高和浅深色调。文字不会随背景一起变淡。
5. 小组件可选小、中、大尺寸，也可自由调节宽度 280–640、高度 240–800 点。拖动小组件标题移动位置，拖动右下角缩放。
   放好后，在主应用的“小组件外观”打开“锁定位置”。锁定后不能从桌面拖动或缩放，右下角缩放标记隐藏，双击完成待办仍然可用。关闭开关可重新拖动。宽高依然可以从主应用调节。位置、锁定状态会在重启后恢复。
6. 小组件待办较多时支持滚动；长内容请在主窗口查看或编辑。
7. 关闭主窗口后，小组件仍会保留在桌面。需要主窗口时，点击 Dock 图标或菜单栏中的清单图标。
8. 编辑与删除按钮位于主窗口每一行右侧，也可右键操作。最近一次待办改动可点击顶部“撤销”恢复；“撤销”不跨重启保留。
9. 如小组件落在其他屏幕，可在“小组件外观”中重置位置，或使用菜单栏中的“将小组件移回主屏幕”。
10. 在菜单栏选择“退出 List Reminder”才会完全退出。再次启动会恢复数据和外观设置。

界面采用中性灰色。桌面小组件只保留标题、待办内容和必要的空状态；没有橙色圆点、进度条、操作提示或保存提示。

这是应用自带的桌面常驻窗口，不通过 macOS 系统“编辑小组件”图库添加。它位于桌面图标上方、普通应用窗口下方，可在多个桌面空间显示。它不会像“置顶窗口”那样覆盖其他应用。

## 数据

数据和设置保存在：

`~/Library/Application Support/List Reminder/reminders.json`

添加、完成、删除及外观修改会自动以原子写入方式保存。无法保存时显示错误，不会把失败的改动当作已保存。损坏的旧文件会先保留 `reminders-unreadable-…json` 备份；无法备份则停止写入。备份整个文件夹即可迁移数据。发布包不包含测试待办。

## 从源码编译

需要完整 Xcode 及包含 `NSGlassEffectView` 的 macOS 26+ SDK。

```sh
./build.sh /path/to/output
./test.sh
```

`build.sh` 生成 Apple Silicon 应用与图标，完成临时签名和签名校验。编译先将源文件复制到临时目录，以避免云同步目录的文件时间戳影响 Swift 编译。当前只构建和验证 arm64，不宣称 Intel 支持。

## 源码导航

- `Sources/Store.swift`：待办、设置、持久化、撤销、错误处理。
- `Sources/DesktopWidget.swift`：不激活的桌面 NSPanel、系统液态玻璃、双击、拖动、缩放和屏幕恢复。
- `Sources/MainView.swift`：待办编辑界面、完成记录、外观调节和实时预览。
- `Sources/App.swift`：应用生命周期、主窗口、菜单栏和快捷键。
- `Tools/Icon.swift`、`Tools/icns.py`：生成原生图标资源。
- `Tests/Regression.swift`：数据、双击路由、持久化、设置边界及保存失败回归验证。

开发时可用 `LIST_REMINDER_DATA_DIR` 环境变量指定隔离数据目录。正式应用默认始终使用上述 Application Support 位置；应用包没有注入此变量。

## 实现依据

使用 Apple 的 [NSGlassEffectView](https://developer.apple.com/documentation/appkit/nsglasseffectview) 实现系统液态玻璃，使用 [nonactivatingPanel](https://developer.apple.com/documentation/appkit/nswindow/stylemask-swift.struct/nonactivatingpanel) 处理不激活主应用的桌面交互。
