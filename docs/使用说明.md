# List Reminder

原生 macOS 待办清单，带可交互的桌面玻璃小组件。

## 运行环境与安装

- Apple Silicon Mac（M 系列芯片），macOS 26 或更新版本。
- 将 `List Reminder.app` 拖入“应用程序”，然后双击打开；也可以直接运行本文件夹中的应用。
- 应用使用本机临时签名，尚未进行 Apple 公证。若另一台 Mac 的系统阻止运行，请在确认来源后，按系统“隐私与安全性”中的正常提示处理。
- 不需要联网、账号、辅助功能权限或屏幕录制权限。

## 使用

1. 点击主窗口的“添加待办”，或点击桌面小组件右下角浮动的液态玻璃「＋」。小组件的快速添加窗居中打开，周围渐暗并播放星场波纹。保存、按 Esc 或点击“取消”后会恢复桌面。系统开启“减弱动态效果”时使用静态背景。
2. 填写待办内容，选择“普通”或“作业”。按需开启“启用倒计时”，在日历中选择截止日期。主清单右上角可按分类筛选。
3. 主窗口与小组件显示同样的倒计时：`7d` 表示还有 7 天，`-2d` 表示超期 2 天，当天显示“今天截止”。超期为红色；今天截止和剩 1–3 天为橙色；剩 4 天及以上为绿色。有截止日期的作业会用同样的颜色描绘左侧小圆圈。
4. 勾选“每日重复”后，截止日期会换成半透明的粉黄渐变“每日”标签。当天完成后任务会收起，第二天按本地日期重新出现。
5. 双击主窗口或小组件的待办即可完成。一般任务会播放烟花和“完成了！！！”。完成小组件清单中的最后一项时，当前屏幕会显示“超级完成！！！”，播放 10 秒满屏香槟与烟花，背景有星云和引力波。动画不阻挡鼠标，并遵循系统“减弱动态效果”设置。
6. 点击主窗口的“成就”查看过去 365 天的完成热力图。颜色越深表示当天完成得越多；点击日期可查完成数。撤销完成或恢复任务会修正对应统计，清除已完成的一次性任务会保留成就记录。
7. 在“小组件外观”调整透明度、色调和宽高。拖动小组件标题可以移动位置；拖动加号右下角的角标可以缩放。锁定位置后仍可添加或完成待办，尺寸也可从主窗口调节。加号浮在列表上方，不占用一整行。
8. 小组件待办较多时支持滚动；长内容请在主窗口查看或编辑。关闭主窗口后，小组件仍会留在桌面。
9. 编辑与删除按钮位于主窗口每一行右侧，也可右键操作。最近一次待办改动可点击顶部“撤销”恢复。
10. 点击 Dock 图标或菜单栏清单图标可以重新打开主窗口。菜单栏也可以将小组件移回主屏幕或完全退出应用。

界面以中性灰色为主，状态颜色用于区分截止时间和每日重复。

这是应用自带的桌面常驻窗口，不通过 macOS 系统“编辑小组件”图库添加。它位于桌面图标上方、普通应用窗口下方，可在多个桌面空间显示。它不会像“置顶窗口”那样覆盖其他应用。

## 数据

数据和设置保存在：

`~/Library/Application Support/List Reminder/reminders.json`

添加、完成、删除及外观修改会自动以原子写入方式保存。升级时保留已有待办、截止日期及小组件设置，并将旧版仍保留的带日期完成记录计入成就。无法保存时显示错误；损坏的旧文件会先保留 `reminders-unreadable-…json` 备份。备份整个文件夹即可迁移数据。发布包不包含个人或测试待办。

## 从源码编译

需要完整 Xcode 及包含 `NSGlassEffectView` 的 macOS 26+ SDK。

```sh
./build.sh /path/to/output
./test.sh
```

`build.sh` 生成 Apple Silicon 应用与图标，完成临时签名和签名校验。编译先将源文件复制到临时目录，以避免云同步目录的文件时间戳影响 Swift 编译。当前只构建和验证 arm64，不宣称 Intel 支持。

## 源码导航

- `Sources/Store.swift`：待办、设置、持久化、撤销、错误处理。
- `Sources/DesktopWidget.swift`：不激活的桌面 NSPanel、系统液态玻璃、双击、拖动、缩放和屏幕恢复。
- `Sources/MainView.swift`：待办编辑界面、完成记录、外观调节和实时预览。
- `Sources/Achievements.swift`：每日完成热力图及累计统计。
- `Sources/App.swift`：应用生命周期、主窗口、菜单栏和快捷键。
- `Sources/Celebration.swift`：完成任务时的全屏烟花和标题动画。
- `Sources/Champagne.swift`：完成全部任务时的香槟、星云与烟花动画。
- `Sources/QuickAddFocus.swift`：快速添加时的暗场、星点与波纹动画。
- `Tools/Icon.swift`、`Tools/icns.py`：生成原生图标资源。
- `Tests/Regression.swift`：数据、双击路由、持久化、设置边界及保存失败回归验证。

开发时可用 `LIST_REMINDER_DATA_DIR` 环境变量指定隔离数据目录。正式应用默认始终使用上述 Application Support 位置；应用包没有注入此变量。

## 实现依据

使用 Apple 的 [NSGlassEffectView](https://developer.apple.com/documentation/appkit/nsglasseffectview) 实现系统液态玻璃，使用 [nonactivatingPanel](https://developer.apple.com/documentation/appkit/nswindow/stylemask-swift.struct/nonactivatingpanel) 处理不激活主应用的桌面交互。
