List Reminder 是一款简约的原生 macOS 待办应用，把待办清单留在桌面，双击一行即可完成。

### 这个版本

- **位置锁定**：把小组件拖到合适位置后，在主应用“小组件外观”开启“锁定位置”，防止误移动。重启后仍保留。
- **简约外观**：移除橙色装饰、进度条和常驻提示，保留玻璃背景、标题与清单。
- **随手完成**：主窗口与桌面小组件均支持双击完成；点击桌面小组件不会打开主窗口。锁定时仍可完成待办。
- **按需调整**：可调背景透明度、宽高、预设尺寸及浅深色调。
- **本地保存**：无需账号或联网，待办与设置自动保存。

### 下载安装

下载下方的 **List-Reminder-macOS-arm64.zip**，解压后把 **List Reminder.app** 拖入“应用程序”并打开。

适用 **Apple Silicon（M 系列芯片）Mac、macOS 26+**。当前应用使用临时签名，尚未通过 Apple 公证。安装包不包含个人待办数据。

桌面小组件由应用直接提供，无需从 macOS 系统小组件图库添加。完整源码与构建方法见仓库首页。

**English**

A minimal native macOS to-do app with a Liquid Glass desktop widget. Version 1.1 adds persistent position locking and a cleaner, neutral appearance. Double-click tasks to complete them, adjust transparency and dimensions, and keep everything stored locally.

Download **List-Reminder-macOS-arm64.zip**, unzip, and move **List Reminder.app** to Applications. Requires **Apple Silicon and macOS 26+**. The app is ad-hoc signed and has not been notarized by Apple. No personal task data is included.
