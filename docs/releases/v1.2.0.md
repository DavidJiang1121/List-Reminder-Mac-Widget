# 截止日倒计时与完成烟花

给待办定个日期，完成时用一场烟花收尾。

- **日历倒计时**：添加或编辑待办时，可以开启倒计时，从日历选择截止日。主窗口和桌面小组件会同步显示。
- **简洁的三色标签**：超期用红色（如 `-2d`）；今天截止和 `1d`–`3d` 用橙色；`4d` 起用绿色。不启用倒计时的事项不显示标签。
- **桌面快速添加**：点击小组件右下角的「＋」，直接打开小窗。锁定位置也能添加，无需打开主窗口。
- **完成烟花**：双击完成待办，当前屏幕播放烟花，中央弹出「完成了！！！」。动画约 3 秒后自动消失，鼠标可以继续操作。

旧版待办与设置继续保留；未设截止日期的旧事项默认无倒计时。

**English**

Version 1.2 adds optional calendar deadlines, a quick-add **+** on the desktop widget, and a full-screen fireworks celebration on task completion. Countdown labels are compact: red for overdue (`-2d`), orange for today and `1d`–`3d`, and green from `4d` onward. Existing tasks and settings are preserved.

Download **List-Reminder-macOS-arm64.zip** for **Apple Silicon and macOS 26+**. The build is ad-hoc signed and has not been notarized by Apple.
