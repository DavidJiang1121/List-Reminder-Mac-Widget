# 每日任务、成就热力图与超级完成

- **作业分类**：添加或编辑时选择「普通」或「作业」，也可以按分类筛选。作业左侧的小圆圈与倒计时同色：超期为红色，今天截止和剩 1–3 天为橙色，剩 4 天及以上为绿色。
- **每日重复**：半透明的粉黄渐变标签显示「每日」，当天完成后收起，第二天自动出现。
- **成就热力图**：像 GitHub 贡献图一样，回看过去 365 天每天完成了多少。旧版中仍有日期的完成记录也会计入。
- **超级完成**：完成最后一项，香槟开瓶喷向整块屏幕，烟花在星云和引力波中绽放。中央显示「超级完成！！！」，整段动画持续 10 秒。

**安装或升级**：下载下方的 `List-Reminder-macOS-arm64.zip`，解压后退出旧版并替换 `List Reminder.app`。原有待办与小组件设置会保留。适用 M 系列芯片的 Mac，需 macOS 26 或更新版本。应用使用临时签名，尚未经过 Apple 公证。

**English:** Adds homework rings, translucent daily-repeat badges, a 365-day completion heatmap, and a ten-second champagne and fireworks show for clearing the list. Existing tasks and widget settings are preserved on upgrade.
